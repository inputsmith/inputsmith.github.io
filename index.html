InputSmith 1.2.1

LATESTNov 7, 2026

Fix: cursor center drift (Mouse + keyboard mode)

  • With Move cursor only while stick is moving and Limit cursor to radius on, releasing the right stick now returns the cursor to exact screen center.
  • Fixes the neutral stick slowly drifting off-center (from radius-edge clipping, pixel rounding, blocked moves, or resting stick noise amplified by response curves).
  • Stick movement and aim feel are unchanged.

InputSmith 1.2.0

Nov 7, 2026
  • Virtual DualSense (USB) output alongside Virtual Xbox, with its own PlayStation-labelled button map and touchpad click
  • More stick curve presets and a Raw stick input mode (no curve or filtering)
  • New cursor curves, including raw cursor input
  • Free-flowing cursor in Mouse + keyboard mode, with an optional snap-to-center button you choose
  • Save, discard, or reset keybinds (practical defaults or all unassigned)
  • F10 and F11 now work even when InputSmith is not focused
  • No more black console window when game output needs administrator approval
  • Mouse + keyboard output keeps running when Windows blocks simulated mouse movement, and shows a warning
